# Shared glossary

| Term | Meaning |
|---|---|
| Agency | Operator organization owning its client workspaces |
| Client | Isolated brand/customer workspace; first pilot is a Thai supermarket |
| Brief | Versioned business objective, audience context, product facts, channel and constraints |
| Opportunity | Testable connection between audience tension, product truth and brand perspective |
| Concept | A distinct creative idea expressing an opportunity, with copy/visual direction and test rationale |
| Proposition | The principal benefit or reason to choose the product |
| Product truth | Approved, scoped factual information about a product/service |
| Proof | Evidence supporting a specific proposition or claim, not persuasion alone |
| Evidence | Source-linked information with provenance, scope and uncertainty |
| Hypothesis | A proposed explanation/motivation to investigate, not an observed fact |
| Finding | Reviewed interpretation tied to a dataset/evidence revision and its limitations |
| Experiment | Defined comparison, primary metric, allocation/context, variants and decision rule |
| Asset specification | Structured, revisioned copy/imagery/layout instructions for production |
| Design bundle | Bounded transport of an approved specification plus assets to Figma |
| Published creative | Platform ad identifier mapped to an immutable internal asset revision |
| Stage profile | Provider/model/settings/cost configuration for one stage |
| Pipeline revision | Validated graph of registered stages and approval dependencies pinned by a run |
| Extension pack | Versioned schema/configuration for bounded industry-specific fields |
| Run | User-requested workflow execution spanning pipeline stages |
| StageAttempt | One execution or retry of a single pipeline stage, with its own lifecycle |
| Fixture | Labelled synthetic deterministic input/output used without a provider call |
| Egress | Data leaving the app to an external service; independent of where the app is hosted |
| Reservation | Conservative hold against internal provider-spend limits, not a customer invoice |
| Approval | Typed human decision on an exact revision; not a model score |
| Policy | Server-enforced access/data/spend rules that client prompts cannot override |
| RLS | PostgreSQL row-level security used in addition to application authorization |
| Dispatch registry | Content-free authoritative metadata used to authorize queued execution scope |
| Gate | Required evidence before a feature/mode is enabled; a document alone does not pass it |
